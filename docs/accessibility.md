# BookTrip v0.3.0 UI・アクセシビリティ検証

目標はWCAG 2.2 AA。これは検証範囲を示す報告であり、完全準拠の認証ではありません。

## 実装

- 白・落ち着いたブルー・ティール、共通の角丸カード、16pxを基本とした日本語フォント、余白、統一アイコンを利用者画面と管理ツールへ適用。
- 作品→旅行条件→旅程確認の3段階を明示。作品の選択状態は枠・チェック・文字で表示。旅行日数にもチェックを付け、色だけに依存しない。
- 管理画面は作品選択を先に表示し、地点名と住所をカードで整理。補足説明は開閉でき、必須条件と未保存状態は常に確認できる。
- 主要操作は44px以上を基本とし、検証した表示中の操作部はWCAG 2.2 AAの24px以上を満たす。文章中のインラインリンクなどは基準の例外を適用。
- 本文スキップ、見出し・ランドマーク、ラベルと入力欄の対応、必須属性、aria-invalidとエラー説明を整備。入力エラー要約から該当欄へ移動でき、画面移動時は隠れた見出しを避けて表示中の見出しへフォーカス。
- 選択・保存・未保存を文字で表示し、保存結果と時間サマリーはライブ領域で通知。管理画面の内部の戻るリンクは既存の未保存確認へ委譲。
- フォーカスは3pxの輪郭と白い間隔で示す。強制カラー表示でも選択枠を維持し、動きを減らす設定に配慮。
- 旅行データ、localStorageキー/形式、時刻計算、マスタ照合は変更しない。直前の機能修正コミット38174cdとUI変更を分離。

## 自動・操作検証

ツールはPlaywright、クラウド側のChromium、axe-core。Web版と単体HTML版（HTTP配信）の両方で検証する。

| 検証 | 対象 |
| --- | --- |
| WCAGタグ | wcag2a、wcag2aa、wcag21a、wcag21aa、wcag22aa、best-practice |
| レイアウト | 1440px、390px、320px（各高さ1000px） |
| 画面状態 | 初期画面、入力エラー、2日プランの旅行条件、旅程、管理画面、管理入力エラー、保存成功、展開したJSON |
| キーボード | Tab/Shift+Tab、スキップ、Spaceで作品選択、エラー要約→入力欄、生成後の見出しフォーカス、管理画面のスキップと帰還 |
| 拡大・リフロー | 390pxでルート文字サイズ200%相当。旅行条件・旅程・管理画面で横はみ出しなし。320 CSS pxでも確認 |
| その他 | 24px操作対象、主要操作44px、フォーカス輪郭、強制カラー時の選択枠、未保存時の内部移動保護 |
| 既存機能 | 単体テスト24件、ブラウザ操作・マスタ反映・日付コピー・半日/1日/2日経路の74項目 |

**結果：Web版19状態＋単体HTML版19状態の計38状態で、自動検出の違反は0件。単体テスト24件、既存機能のブラウザテスト74項目も通過した。** キーボード操作、200%相当の文字拡大、320pxリフロー、強制カラーの選択枠も通過した。追加で行間1.5、文字間隔0.12em、単語間隔0.16em、段落間隔2emを適用し、390px/320pxの旅行条件・旅程・管理画面（両版の計12ケース）で横はみ出しがないことを確認した。

axeの判定保留はcolor-contrastのみ（各版19状態）。グラデーションと疑似要素によるもので、下記の指定色の数値確認で補完した。これは全ピクセル・全状態に対する自動判定ではない。実行コマンドは `npm test`、`npm run typecheck`、`npm run build`、`npm run build:standalone`、`npm run test:a11y`。通常のブラウザ操作は `test:e2e`、`test:standalone`、`test:mvp`、`test:routes`、`test:integration`。

## 未確認・残る確認事項

- Windows ARM64のEdge実機での新版単体HTMLのfile://表示、NVDA/JAWS/VoiceOverによる実際の読み上げ・操作はこの環境では未確認。ラベル、ARIA、フォーカスは検証したが、読み上げの順序・長さ・快適さの実機確認が必要。
- iOS Safari/Android実機、実際のWindows 400%ブラウザズーム、OS文字拡大、Windowsの強制カラー各テーマは未確認。320 CSS px、200%相当の文字サイズ、Chromiumのforced-colorsで近似検証している。
- Google Maps側の画面・日時設定は外部サービスで検証対象外。BookTripには自動設定ができない旨と手動操作の案内を表示。
- 利用者参加のユーザビリティテストは未実施。高齢者・スクリーンリーダー利用者を含む実利用で、長い旅程や管理カードの読みやすさを追加確認する。
- ブラウザ自体の再読み込み・閉じる・履歴操作で未保存の入力を保持する機能は従来どおり対象外。未保存表示を確認し、保存ボタンを使用する。保存済みマスタは保持する。

自動検証で問題が検出されなくても、WCAGの全達成基準への適合が確定するものではない。
